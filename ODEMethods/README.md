# Решение обыкновенных дифференциальных уравнений

Программа численно решает задачу Коши для обыкновенного дифференциального уравнения первого порядка

$$ y'(x)=f(x,\space y(x)), \qquad y(x_0)=y_0, $$

на отрезке $[x_0,x_{\mathrm{End}}]$.

Отрезок разбивается на $n$ равных шагов.

---

### Сетка:

Шаг сетки: $h=\frac{x_{\mathrm{End}}-x_0}{n}$.

Узлы: $x_i=x_0+ih, \qquad i=0,1,\dots, n$.

Таким образом, ${x_n=x_{\mathrm{End}}}$.

Начальное значение: $y_0=y(x_0)$.

Программа вычисляет приближённые значения $y_0,y_1,\dots, y_n$ во всех узлах сетки.

[См. в коде.](ODE.hpp#l31-L41)

---

## Методы

### 1. Явный метод Эйлера

На каждом шаге: $y_{i+1}=y_i+h f(x_i, y_i) $, где $x_{i+1}=x_i+h$.

Метод имеет **первый порядок точности**: глобальная погрешность имеет порядок $O(h)$.

[См. в коде.](ODE.hpp#L47-L64)

---

### 2. Улучшенный метод Эйлера (Хойна)

Сначала вычисляются две оценки производной:

$$
\begin{gathered}
{k_1 = f(x_i,y_i)}\\
{\widetilde y_{i+1} = y_i + h k_1}\\
{k_2 = f(x_i+h,\widetilde y_{i+1})}
\end{gathered}
$$

Затем значение в следующем узле определяется как среднее двух наклонов:

$$\boxed{ y_{i+1} = y_i+\frac{h}{2}(k_1+k_2)}$$

Тогда полностью формула будет такой:

$$
\boxed{
y_{i+1} = y_i + \frac h2
\left[
f(x_i,y_i) +
f\left(x_i+h,y_i+h f(x_i,y_i)\right)
\right]
}
$$

Метод имеет **второй порядок точности**: $O(h^2)$.

[См. в коде.](ODE.hpp#L66-L90)

---

### 3. Метод Рунге–Кутты второго порядка (метод средней точки)

Сначала вычисляется:

$$k_1=f(x_i,y_i)$$

Затем производная оценивается в середине шага:

$$k_2 = f\left(x_i+\frac h2, y_i+\frac h2 k_1 \right)$$

Итоговая формула:

$$\boxed{ y_{i+1}=y_i+h k_2 }$$

или

$$\boxed{ y_{i+1} = y_i+ h f\left(x_i+\frac h2, y_i+\frac h2 f(x_i,y_i)\right)}$$

Метод имеет **второй порядок точности**: $O(h^2)$.

[См. в коде.](ODE.hpp#L93-L115)

---

### 4. Классический метод Рунге–Кутты четвёртого порядка (RK4)

На каждом шаге вычисляются четыре коэффициента:

$$
\begin{gathered}
{k_1=f(x_i,y_i)},\\
{k_2= f\left(x_i+\frac h2, y_i+\frac h2 k_1 \right)},\\
{k_3= f\left(x_i+\frac h2, y_i+\frac h2 k_2 \right)},\\
{k_4=f(x_i+h,y_i+h k_3)}.
\end{gathered}
$$

После этого:

$$\boxed{ y_{i+1} = y_i+ \frac h6(k_1+2k_2+2k_3+k_4)}$$

Метод имеет **четвёртый порядок точности**: $O(h^4)$.

При одинаковом шаге RK4 обычно обеспечивает значительно меньшую погрешность, чем методы первого и второго порядка.

[См. в коде.](ODE.hpp#L118-L145)

---

### 5. Неявный метод Эйлера

В отличие от явного метода Эйлера, производная вычисляется в следующем узле: $y_{i+1} = y_i+h f(x_{i+1}, y_{i+1})$.

Здесь неизвестное $y_{i+1}$ находится по обе стороны уравнения, поэтому на каждом шаге необходимо решить нелинейное
уравнение.

Введём функцию:

$$\boxed{ F(z)=z-y_i-hf(x_{i+1},z) }$$

Тогда необходимо найти корень: $F(z)=0$.

После нахождения корня: $y_{i+1}=z$.

Неявный метод Эйлера имеет **первый порядок точности**: $O(h)$.

[См. в коде.](ODE.hpp#L148-L197)

---

### 6. Метод Ньютона

Для решения уравнения: $F(z)=0$ используется метод Ньютона:

$$\boxed{ z_{k+1} = z_k-\frac{F(z_k)}{F'(z_k)} }$$

Для $F(z)=z-y_i-hf(x_{i+1}, z)$ производная имеет вид:

$$\boxed{ F'(z) = 1-h\frac{\partial f}{\partial y}(x_{i+1},z) }$$

Следовательно, одна итерация метода Ньютона записывается как:

$$
\boxed{
z_{k+1} = z_k - \frac
{ z_k-y_i-hf(x_{i+1},z_k)}
{ 1-h\frac{\partial f}{\partial y}(x_{i+1},z_k) }
}
$$

В программе шаг Ньютона может быть записан через приращение:

```c++
const double delta = -F / dF;
z += delta;
```

То есть:

$$\Delta z_k=-\frac{F(z_k)}{F'(z_k)}, \qquad z_{k+1}=z_k+\Delta z_k$$

---

#### Начальное приближение:

В качестве начального приближения используется один шаг явного метода Эйлера:

$$\boxed{ z_0=y_i+h f(x_i,y_i) }$$

Это обычно является хорошим начальным приближением для решения на следующем шаге.

---

#### Условие остановки:

Итерации прекращаются, если изменение решения достаточно мало: $|\Delta z| \leq \varepsilon(1+|z|)$.

По умолчанию используется $\varepsilon=10^{-12}$.

Также задаётся максимальное количество итераций: $k_{\max}=50$.

## Test-Case

$$ y'=y, \qquad y(0)=1 $$

Её точное решение:

$$ \boxed{ y(x)=e^x } $$

Расчёт выполняется на отрезке $[0,1]$ с использованием $10$ шагов, поэтому $h=0.1$.

В точке $x=1$ точное значение равно $e\approx2.718281828$.

## Сравнение методов

| Метод                   | Порядок точности |
|-------------------------|-----------------:|
| Явный Эйлер             |                1 |
| Улучшенный Эйлер (Хойн) |                2 |
| RK2 (средняя точка)     |                2 |
| RK4                     |                4 |
| Неявный Эйлер           |                1 |

При одинаковом шаге методы второго порядка обычно точнее метода Эйлера, а RK4 обеспечивает ещё более высокую точность.

Неявный Эйлер имеет первый порядок точности, но его особенностью является неявная формула, требующая решения нелинейного уравнения на каждом шаге.

---

## Вычислительная сложность

Для явных методов на $n$ шагах выполняется $O(n)$ вычислений функции $f$.

Для неявного метода Эйлера на каждом шаге дополнительно выполняется несколько итераций метода Ньютона. Если среднее
число итераций Ньютона равно $k$, то вычислительная сложность по числу итераций имеет порядок $O(nk)$.
