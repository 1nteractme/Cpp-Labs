# Метод простой итерации

## Теория

Рассматривается система линейных алгебраических уравнений:

$$ Ax=b, $$

где:

* $A$ – матрица коэффициентов;
* $x$ – вектор неизвестных;
* $b$ – вектор правой части.

Для применения метода простой итерации система должна быть преобразована к эквивалентному виду:

$$ x=Bx+d, $$

где $B$ – матрица итерационного процесса, а $d$ – постоянный вектор.

В качестве начального приближения выбирается вектор

$$ x^{(0)}=(x_1^{(0)},x_2^{(0)}, \dots, x_m^{(0)}) $$

Затем последовательно вычисляются приближения:

$$ x^{(k+1)}=Bx^{(k)}+d $$

При выполнении условия

$$ \|B\|<1, $$

итерационный процесс сходится к единственному решению системы.

Система решается непосредственно методом последовательного исключения диагонального элемента. Для $i$-й строки системы итерационная формула имеет вид:

$$
x_i^{(k+1)} = \frac
{ b_i-\displaystyle\sum_{\substack{j=1\\ j \ne\ i}}^m a_{ij}x_j^{(k)} }
{ a_{ii} }
$$

Таким образом, на каждой итерации новое значение $x_i$ вычисляется через значения остальных неизвестных, полученных на предыдущей итерации.

### Условие сходимости

Для применения метода необходимо выполнение условия сходимости итерационного процесса. Достаточным условием является:

$$
\|B\|<1
$$

На практике также часто используется условие диагонального преобладания матрицы $A$:

$$
|a_{ii}|>\sum_{j\ne i}|a_{ij}|,
\qquad i=1,\dots,m
$$

Если матрица обладает строгим диагональным преобладанием по строкам, это является достаточным условием сходимости соответствующего итерационного процесса.

## Практическая реализация

### Структура проекта

Основная реализация метода находится в классе:

```text
SimpleIteration
```

Класс хранит:

* `A` – матрицу коэффициентов;
* `B` – вектор правой части;
* `N` – текущее приближение решения.

```cpp
class SimpleIteration
{
private:
    vector<vector<double>> A;
    vector<double> B;
    vector<double> N;
};
```

Размер вектора `N` определяется на основании размера матрицы `A`, поэтому алгоритм может работать с матрицами различного порядка.

### Чтение исходных данных

Матрица и вектор считываются из файлов и передаются в конструктор класса:

```cpp
SimpleIteration(const vector<vector<double>>& matrix, const vector<double>& vector): A(matrix), B(vector) {}
```

Матрица записывается в файл построчно. Элементы строки разделяются запятыми:

```text
4, -1, 1,
-1, 4, -1,
1, 1, 3
```

Вектор правой части может иметь вид:

```text
7, 1, 5
```

### Начальное приближение

Начальное приближение задаётся нулевым вектором:

$$ x^{(0)}=(0,0,\dots,0) $$

В программе это выполняется методом:

```cpp
void InitN() { N.assign(A.size(), 0.0); }
```

## Метод `Iteration`

Метод:

```cpp
vector<double> Iteration(const vector<double>& x)
```

вычисляет одно новое приближение решения системы.

Для каждой строки матрицы вычисляется:

$$
x_i^{(k+1)} = \frac
{ b_i-\displaystyle\sum_{j \ne i}a_{ij}x_j^{(k)} }
{ a_{ii} }
$$

В программе реализовано следующим образом:

```cpp
vector<double> Iteration(const vector<double>& x)
{
    vector<double> result(A.size());

    for (size_t i = 0; i < A.size(); i++)
    {
        double sum = 0.0;

        for (size_t j = 0; j < A.size(); j++)
        {
            if (i != j)
                sum += A[i][j] * x[j];
        }

        result[i] = (B[i] - sum) / A[i][i];
    }

    return result;
}
```

Метод возвращает вектор `result`, содержащий новое приближение:

$$ x^{(k+1)} $$

В программе используются циклы по размеру матрицы. Поэтому метод не зависит от конкретного порядка системы.

## Метод `MSI`

Основной алгоритм реализован в методе:

```cpp
void MSI(const double epsilon)
```

где `epsilon` – заданная точность вычислений.

На каждой итерации:

1. Вычисляется новое приближение:

   ```cpp
   vector<double> I = Iteration(N);
   ```

2. Вычисляется максимальная разность между новым и предыдущим приближением:

$$ \varepsilon_k=\max_i\left|x_i^{(k+1)}-x_i^{(k)}\right| $$

3. Новое приближение становится текущим:

   ```cpp
   N = I;
   ```

4. Проверяется критерий окончания итераций:

   ```cpp
   if (error < epsilon) break;
   ```

Таким образом, итерационный процесс прекращается, когда максимальное изменение компонентов вектора становится меньше заданной точности:

$$
\max_i
\left|
x_i^{(k+1)}-x_i^{(k)}
\right|
<\varepsilon
$$

## Пример

Для системы

$$
\begin{cases}
4x_1-x_2+x_3=7,\\
-x_1+4x_2-x_3=1,\\
x_1+x_2+3x_3=5
\end{cases}
$$

имеем:

$$
A=
\begin{pmatrix}
4&-1&1\\
-1&4&-1\\
1&1&3
\end{pmatrix},
\qquad
b=
\begin{pmatrix}
7\\
1\\
5
\end{pmatrix}
$$

При начальном приближении

$$ x^{(0)}=(0,0,0) $$

первая итерация имеет вид:

$$ x_1^{(1)} = \frac{7+x_2^{(0)}-x_3^{(0)}}{4}, $$

$$ x_2^{(1)} = \frac{1+x_1^{(0)}+x_3^{(0)}}{4}, $$

$$ x_3^{(1)} = \frac{5-x_1^{(0)}-x_2^{(0)}}{3} $$

После этого полученный вектор используется для вычисления следующей итерации.

## Использование

Пример создания объекта в ``main.cpp`` (точка входа программы):

```cpp
int main()
{
    const Data data;

    constexpr double eps = 0.001;
    const auto matrix_A = data.Matrix;
    const auto vector_B = data.Vector;

    SimpleIteration methode(matrix_A, vector_B);

    methode.printData();
    methode.MSI(eps);

    return 0;
}
```

где:

* `data.Matrix` – матрица $A$;
* `data.Vector` – вектор $b$;
* `0.001` – требуемая точность $\varepsilon$.

## Ограничения

Перед запуском метода необходимо убедиться, что:

* матрица $A$ квадратная;
* количество элементов вектора $b$ совпадает с размером матрицы;
* диагональные элементы $a_{ii}$ не равны нулю;
* для выбранной итерационной схемы выполняется условие сходимости.

При нарушении условий сходимости метод может не сойтись или количество итераций может значительно увеличиться.

---

## Результат

После завершения итерационного процесса программа выводит найденное приближённое решение:

$$ x\approx x^{(k)} $$

Точность определяется параметром `epsilon`.
