# Метод прогонки

## Теория

Метод прогонки является частным случаем метода [Гаусса](https://github.com/1nteractme/Cpp-Labs/tree/semester-3/Gauss) и используется для решения систем линейных уравнений вида $Ax = B$, где $A$ – **трёхдиагональная матрица**.

_Трёхдиагональной матрицей_ называется матрица такого вида, где во всех остальных местах, кроме главной диагонали и двух соседних с ней, стоят нули.

Метод прогонки состоит из двух этапов: _**прямой прогонки и обратной прогонки**_. 

На первом этапе определяются прогоночные коэффициенты, а на втором – находят неизвестные x.

---

### Алгоритм выполнения метода прогонки
СЛАУ имеет вид:

$$
\begin{pmatrix}
    b_1 & c_1 & 0 & \cdots & 0\\
    a_2 & b_2 & c_2 & \ddots & \vdots\\
    0 & a_3 & b_3 & \ddots & 0\\
    \vdots & \ddots & \ddots & \ddots & c_{n-1}\\
    0 & \cdots & 0 & a_n & b_n
\end{pmatrix}
\begin{pmatrix}
    x_1\\
    x_2\\
    x_3\\
    \vdots\\
    x_n
\end{pmatrix}=
\begin{pmatrix}
    p_1\\
    p_2\\
    d_3\\
    \vdots\\
    d_n
\end{pmatrix}
$$

Прямая прогонка состоит в вычислении прогоночных коэффициентов $\alpha i$ и $\beta i$, где $i$ – номер строки матрицы.
Этот этап выполняется при $i = 1\dots n$ строго по возрастанию значения $i$.

1. В первой строке матрицы $(i = 1)$ используются формулы:

$$
{y_1 = b_1},
\qquad
{\alpha_1 = \frac{-c_1}{y_1}},
\qquad
{\beta_1 = \frac{d_1}{y_1}}
$$

2. Для строк $i$ от 2 до $n-1$ используются рекуррентные формулы:

$$
{y_i = b_i + a_i\alpha_{i-1}},
\qquad
{\alpha_i = \frac{-c_i}{y_i}},
\qquad
{\beta_i = \frac{d_i-a_i\beta_{i-1}}{y_i}}
$$

3. При $i = n$ прямая прогонка завершается вычислением:

$$
{y_n = b_n + a_n\alpha_{n-1}},
\qquad
{\beta_n = \frac{d_n-a_n\beta_{n-1}}{y_n}}
$$

После этого производится обратная прогонка, в которой происходит вычисление неизвестных $xi$.
Этот этап выполняется при $i = n...1$ строго по убыванию значения $i$.

4. В последней строке матрицы $(i = n):\qquad xn = \beta n$.
5. Для всех остальных строк при $i$ от $n-1$ до 1 применяется формула:

$$
x_i = \alpha_ix_{i+1} + \beta_i
$$

## Практика
### Назначение

Программа решает трехдиагональную СЛАУ методом прогонки, также известным как алгоритм Томаса.

Система имеет вид:

```c++
b0*x0 + c0*x1 = d0
a1*x0 + b1*x1 + c1*x2 = d1
...
a(n-1)*x(n-2) + b(n-1)*x(n-1) = d(n-1)
```

[Матричный вид](#алгоритм-выполнения-метода-прогонки)

---

### Идея метода

Искомое решение представляется в виде:

```c++
x[i] = alpha[i] * x[i+1] + beta[i]
```

Сначала выполняется прямой ход, во время которого вычисляются `alpha` и `beta`. 
Затем выполняется обратный ход.

Начальные коэффициенты [(см. в коде)](Tridiagonal.hpp#L87-L88):

```c++
alpha[0] = -c[0] / b[0]

beta[0] = d[0] / b[0]
```

Для остальных строк [(см. в коде)](Tridiagonal.hpp#L92-L898):

```c++
alpha[i] = -c[i] / (b[i] + a[i] * alpha[i-1])

beta[i] = (d[i] - a[i] * beta[i-1]) / (b[i] + a[i] * alpha[i-1])
```

Последняя неизвестная [(см. в коде)](Tridiagonal.hpp#L102):

```c++
x[n-1] = beta[n-1]
```

После этого [(см. в коде)](Tridiagonal.hpp#L104-L105):

```c++
x[i] = alpha[i] * x[i+1] + beta[i]
```

### Класс Tridiagonal

Основной класс [Tridiagonal](Tridiagonal.hpp#L9):

```c++
class Tridiagonal
```

Основной метод [solve(...)](Tridiagonal.hpp#L77-L108):

```c++
[[nodiscard]] vector<double> solve(...) const
```

Параметры:

* `a` – нижняя диагональ;
* `b` – главная диагональ;
* `c` – верхняя диагональ;
* `d` – правая часть.

Возвращается вектор решения `x`.

### Test-Case

Решается система:

```c++
const vector<vector<double>> s = {
        {2, -1, 0},
        {-1, 2, -1},
        {0, -1, 2}
    };
```

```c++
const vector<double> d = {1, 0, 1};
```

Получаем:

```c++
x1 = 1
x2 = 1
x3 = 1
```

## Сложность

Для системы размера `n`: время – `O(n)`, память – `O(n)`.

Это значительно эффективнее общего метода [Гаусса](https://github.com/1nteractme/Cpp-Labs/tree/semester-3/Gauss) для трехдиагональных систем.
